Access code / admin PIN

Codes are held in the Apps Script backend, not in this page or config.json. To change them: Apps Script → Project Settings → Script Properties → ACCESS_CODE / ADMIN_PIN. New codes apply to the next sign-in straight away. To sign everyone out, delete TOKEN_SECRET.
